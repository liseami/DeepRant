# src-tauri/src/

成员清单
lib.rs: 生命周期与原生业务/系统 IPC 登记，管理更新状态；仅主窗口可恢复损坏设置，成功后重建快捷键；Ready 先显示再初始化，警告日志不记录原文。
desktop_services.rs: Rust 桌面服务边界，按窗口身份限制文本复制、固定外链 ID 和单录屏 URL；应用级主题驱动标题栏与全部 WebView 深浅色；前端不获得通用系统或路径插件能力，asset 仍按 Range 读取原资源。
input_diagnostics.rs: 实时权限与真实注册状态、最近输入的只内存快照；固定系统设置入口不代替用户授权，热键和复制阶段不进磁盘日志。
main.rs: 桌面程序入口，只调用库运行函数。
credentials.rs: 系统钥匙串凭据唯一边界，以协议及端点隔离 Key；仅主窗口模型编辑可按服务查看，不进入公开设置或诊断。
store.rs: 设置校验与升级迁移；单锁写入 SQLite，加载时剥除旧模型运行时状态；格式错误仅经显式备份恢复，系统凭据保留；启动外观不等待钥匙串。
store_tests.rs: 设置迁移与写入边界回归，覆盖 1.1.7、旧运行时属性、凭据分离、损坏字段脱敏及合法设置往返。
settings_db.rs: 单行 JSON 文档的 SQLite 事务，保留未知根字段；首次读旧文件，之后数据库唯一权威；恢复前完整备份固定设置文件，备份失败不写默认值。
ai_translator.rs: 模型请求与最终文本解析；公网强制 Key，本机 / 局域网 Key 可选；直接消费可查看的同源提示词，现代 OpenAI 使用 developer/完成预算，Qwen 默认关闭思考，旧模型兼容不污染其他协议。
translation_prompt.rs: Rust 完整生效提示词唯一生成源；嘴臭创造性改写、自定义要求优先；主窗口查看/复制只读取已保存设置，不访问模型 Key。
model_presets.rs: Rust 唯一供应商目录，向界面提供当前预设、官方端点与精确 ID；历史标签仅兼容，迁移不重置用户地址。
model_config.rs: 模型契约、端点归一与回环/私有网络/官方服务分类；仅回环与私有网段（RFC 1918、链路本地、CGNAT、ULA、.local）允许 http，域名不经解析判断；前端不重复 URL 策略，运行时属性不持久化。
model_editor.rs: 原生测连诊断、计时与显式复制最近报告；仅含服务/协议/模型和脱敏结果，不接收前端拼装诊断。
native_keyboard.rs: macOS 键盘创建、布局查询及事件注入只在主线程；后台误调用先拒绝，网络和等待不占主线程。
scenes.rs: 游戏语境与地区提示词；模型请求读取设置后组合提示词。
shortcut.rs: 规范按键、注册及持久化事务；Pressed/Released/过期周期进入诊断，真实绑定状态可查询，录制使旧周期失效。
shell_helper.rs: 场景选区、焦点与剪贴板恢复；Dota 2 读取整条聊天，其余游戏从光标到行首，日常保留原选区；每次短注入交给 native_keyboard，AX 错误保留阶段码。
inline_translation.rs: 可见占位的原位生命周期；Dota 2 仅准备时全选占位，提交/回滚不重选，当前选区精确核验后粘贴一次；无法回滚的原文只存内存供显式复制。
game_composer.rs: 游戏浮窗与 token 会话；自动游戏输入为 LoL/星际公民使用浮窗，显式输入模式优先、日常自动模式原位；原生整理单行译文并拒绝过期编号，回填失败保留草稿，取消释放输入锁。
composer_target.rs: 原游戏应用/窗口生命周期与焦点确认；无游戏 hook 或键盘监听，恢复真实焦点后允许写入。
tray.rs: 托盘菜单与窗口可见性，直接调度 Rust 更新检查；不让前端转发系统动作。
desktop_updates.rs: 更新唯一权威，主窗口意图与单调快照；原生资源/累计进度/后台安装，旧编号与版本拒绝安装，官方签名版本验证后才替换。
updater_tests.rs: 官方 updater 签名信任边界；校验真实发布字节、篡改拒绝和版本绑定。
